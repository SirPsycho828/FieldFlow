# Design System — FieldFlow

> Generated by Design Overhaul skill. This document is the single source of truth for all design decisions.

## Design Direction

**Direction:** Terra Firma — organic warmth meets professional craft
**Signature Element:** Topographic contour line SVG patterns as decorative backgrounds behind headers and empty states

---

## Typography

### Fonts
- **Heading:** Merriweather (300, 400, 700, 400italic)
- **Body:** Cabin (400, 500, 600, 700)

## Animation

| Token | Value | Usage |
|-------|-------|-------|
| --duration-fast | 150ms | Micro-interactions (hover, focus) |
| --duration-normal | 250ms | State transitions |
| --duration-slow | 400ms | Page transitions, reveals |
| --easing-default | cubic-bezier(0.4, 0, 0.2, 1) | General motion |
| --easing-spring | cubic-bezier(0.34, 1.56, 0.64, 1) | Bouncy entrances |
| --easing-out | cubic-bezier(0, 0, 0.2, 1) | Exit animations |

**Signature Animation:** Topographic contour line SVG patterns — thin, muted lines in the border/muted color behind page headers and empty states, evoking landscape survey maps. Static visual texture, not motion.
